# 插件功能

[返回 README](../README.md) · [实现原理](architecture.md) · [安装方式](installation.md)

## 悬浮图标与设置

| 操作 | 行为 |
| --- | --- |
| 点击图标 | 打开或关闭练习面板 |
| 长按图标 | 依次切换倍率预设 |
| 拖动图标 | 调整屏幕位置 |
| 游玩时隐藏图标 | 切换开关，默认关闭；游玩期间隐藏，停止游玩更新后约一秒恢复 |

暂停时若游戏停止更新，也会恢复图标，便于打开面板。配置保存于 `Documents/xrcdemo.plist`；不存在时使用默认值。日志位于 `Documents/xrcdemo.log`。

## 播放与循环

| 功能 | 使用方式 | 说明 |
| --- | --- | --- |
| 播放倍率 | 拖动倍率滑杆或长按图标 | 改变谱面时钟速度 |
| 音乐变速 | 开启开关，默认开启 | 音乐跟随倍率并保持音高；关闭后只改变谱面速度 |
| 进度跳转 | 点击或拖动时间轴，使用前后跳转按钮 | 以音频时间为坐标；取消拖动不跳转 |
| 回跳重播 | 开启开关，默认关闭 | 回退时恢复相关音符和判定状态，重新练习该段 |
| A/B 循环 | 设置起点 A、终点 B，再开启循环 | 到 B 自动回 A 并重播；换歌不自动清除循环范围 |
| 自动演奏 | 开启开关，默认关闭 | 用于本地演示和观察谱面 |

普通时间跳转和回跳重播的作用不同：未启用重播时，导航不会恢复已判定音符或回滚计分。跳转会等待音频落位后再同步谱面；定位失败、超时或换场景时会取消事务。

## 判定与倍率适配

| 功能 | 默认状态 | 行为 |
| --- | --- | --- |
| 四档判定窗口 | 25 / 50 / 100 / 120 ms | 面板调整窗口，数值按递增关系保存 |
| 锁定判定区间 | 关闭 | 按实际时间维持判定窗口，减少倍率改变造成的容错变化 |
| 倍率适应偏移 | 关闭 | 内部用户偏移乘播放倍率，游戏设置显示值不变 |
| 倍率适应流速 | 关闭 | 内部流速乘倍率倒数，游戏设置显示值不变 |

两项倍率适配支持游玩中切换；跳转事务期间暂缓，下一安全帧应用。关闭后恢复原设置的效果。原有手动流速输入已移除，旧 `noteFlow` 配置不再应用。

例如游戏设置流速 5.0、偏移 100 ms：

| 倍率 | 内部等效流速 | 内部用户偏移 | 设置显示 |
| --- | --- | --- | --- |
| 0.5 | 10.0 | 50 ms | 5.0 / 100 ms |
| 1.0 | 5.0 | 100 ms | 5.0 / 100 ms |
| 2.0 | 2.5 | 200 ms | 5.0 / 100 ms |

## Konzetsu 练习

适用于 **7.0.256 配套构建**，可以用于任意曲目。效果选择和两个开关默认不启用，在下一次加载谱面时应用；本局采用开局快照。

| 控件 | 操作 |
| --- | --- |
| 选择挑战 | 每次点击循环切换：下隐 → 变速 → 上下反 → 点血条 → 综合 → 下隐 |
| 启用 | 应用当前选择的效果 |
| 挑战 | 与“启用”同时打开时使用挑战血条；否则使用普通橘色 HARD 血条 |

| 选项 | 效果 |
| --- | --- |
| 下隐 | 使用原生下隐渲染 |
| 变速 | 使用挑战的流速变化，与插件播放倍率独立 |
| 上下反 | 使用原生音符转换 |
| 点血条 | 原生可点击血条；需同时打开“挑战” |
| 综合 | 原生支持曲目使用各自时间表，其他曲目使用按谱面时长缩放的练习时间表 |

不提供常规挑战 5 选项。综合的普通歌曲时间表是练习适配，不代表游戏为所有歌曲提供了原生最终考核。原生重试可能复用本局谱面，切换后应退出选曲再开局。游戏内原生挑战仍使用自身逻辑。

## 内容与网络

| 功能 | 作用 | 边界 |
| --- | --- | --- |
| cb 内容外置 | 默认开启，将内容目录移到 `Documents/cb` | 关闭不会自动撤销已创建的目录链接 |
| cb 内容定制 | 控制内容校验及清理保护 | 保留原生就绪判断，不能将空目录视为已初始化 |
| 私服接入 | 面板设置地址，默认关闭 | 重写匹配的 API 地址，保留路径和参数；网络可用性还取决于设备与服务 |
| 链系统保护 | 对部分内容查表的空值提供保护 | 不会补齐资源或修复所有资源格式错误 |

插件不提供独立的 FV/DO 解锁按钮；相关原生修改不属于插件功能。默认部署也不启用可选的 `unlock_own` 拥有链覆盖。

## 验证范围

7.0.256 启动及 Konzetsu 效果已有用户实测反馈。最新循环选择和隐藏图标构建通过测试，但仍需设备复测；倍率适配、特殊挑战组合以及 Hold / Arc 连续判定也应逐项验收。构建成功不等于所有功能在所有系统上均已验证。
