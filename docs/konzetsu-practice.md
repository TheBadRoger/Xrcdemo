# Konzetsu 离线练习

适用于插件的 **7.0.256 构建**，默认关闭。主程序与动态库都需要包含这次新增的练习接口；只替换旧包中的动态库不能启用完整功能。

五个选项均面向任意曲目，不使用原挑战的可玩曲目名单限制选择。

## 控件

| 控件 | 行为 |
| --- | --- |
| 选择挑战 | 每次点击依次切换：下隐 → 变速 → 上下反 → 点血条 → 综合 → 下隐；不列常规挑战 5 |
| 启用 | 下一次加载谱面时应用所选练习效果 |
| 挑战 | 与“启用”同时打开时使用挑战血条，否则使用普通橘色 HARD 血条 |

两个按钮均为切换开关，选择和开关状态保存在 `Documents/xrcdemo.plist`。只打开“挑战”不会改变游戏血条。

播放区另有“游玩时隐藏图标”开关，默认关闭，设置会保存。开启后在游玩期间隐藏悬浮图标，停止游玩帧更新后约一秒自动恢复；暂停时若游戏停止更新，也会恢复图标，便于重新打开面板。

## 使用步骤

1. 在选曲界面打开插件面板，选择练习效果。
2. 打开“启用”；需要挑战血条时再打开“挑战”。
3. 进入谱面，本局固定采用加载时的设置。
4. 游玩中修改设置后，退出到选曲界面再进入谱面。原生重试可能复用已经转换的谱面，不能保证应用新设置。

## 效果范围

| 选项 | 说明 |
| --- | --- |
| 下隐 | 使用原生下隐渲染路径 |
| 变速 | 使用原生挑战的谱面流速变化，与插件播放倍率分开 |
| 上下反 | 使用原生音符转换路径 |
| 点血条 | 使用原生可点击挑战血条；需同时打开“挑战”才能体验。界面第四项对应原生点击血条逻辑，而非检查点逻辑 |
| 综合 | 四首原生支持歌曲使用各自原始时间表；其余歌曲使用按谱面音符时长缩放的练习时间表 |

综合的普通歌曲适配使用 Arghena 的效果顺序作为模板，包含变速、上下反、下隐与血条阶段；它是练习适配，不代表游戏原本为每首歌曲提供了综合考核。缩放采用最后一个解析音符的起点加 500 ms，长尾音频可能不在效果范围内。

插件保留游戏真实的挑战选择与通关状态。已经从游戏进入的原生挑战沿用游戏自身逻辑，插件练习设置不覆盖它。

## 部署与检查

- 新增接口需要重新部署到主程序，使用本次 7.0.256 动态库配套构建。
- 7.0.255 构建保留原有插件功能，挑战控件禁用。
- 若控件提示缺少完整练习桩，请检查主程序是否包含全部新增接口；不能把“配置已保存”当作已生效。
- 日志中 `[konzetsu] round=` 表示捕获了新谱面的设置；`generated combined schedule` 表示为普通歌曲生成了综合时间表。
- 构建和单元测试通过后仍需 iPad 实测：每个效果、橘色/挑战血条、点击血条、切换后重新开局、循环回跳及重启后的设置保存。
