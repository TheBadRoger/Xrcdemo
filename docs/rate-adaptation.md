# 倍率自动适配

面板新增两个独立开关，替代原有的手动下落流速输入。默认关闭，开启状态会保存。

| 开关 | 内部修正 | 游戏设置显示值 |
| --- | --- | --- |
| 倍率适应流速 | 原流速 × 1 / 播放倍率 | 保持原值 |
| 倍率适应偏移 | 用户偏移 × 播放倍率 | 保持原值 |

例如原流速为 5.0、用户偏移为 100 ms：

| 播放倍率 | 内部等效流速 | 内部用户偏移 |
| --- | --- | --- |
| 0.5 | 10.0 | 50 ms |
| 1.0 | 5.0 | 100 ms |
| 2.0 | 2.5 | 200 ms |

偏移系数来自谱面时钟：谱面毫秒随倍率变化，要保留相同的实际时间延迟，用户偏移也需乘倍率。只补偿用户设置的偏移；谱面自身的 AudioOffset 和音频输出缓冲延迟分别处理。

## 使用步骤

1. 在游戏设置中设置平常使用的偏移、流速。
2. 开启音乐变速，并在插件面板选择播放倍率。
3. 分别开启所需的自动适配开关。
4. 游玩中可切换开关或倍率；在下一安全帧应用。跳转事务完成前暂缓调整。
5. 关闭后恢复原有设置的效果，无需重新填写数值。

流速通过谱面渲染深度缩放实现，并同步缩放显示窗口，不重建谱面、不清空判定和分数。偏移通过增量调整时钟实现，跳转校准会扣除该增量，避免重复累加。

## 构建与部署

- 支持 7.0.255、7.0.256 的对应构建，两个版本的地址不同。
- 必须配套使用新动态库和 `adapt_window` 注入站点；注入工具会拒绝不配套的旧动态库。
- 流速开关只有在渲染函数指纹与注入站点验证通过时才可用。
- 旧版 `noteFlow` 保存值不再应用；旧手动流速注入站点退出默认部署。
- 数学测试覆盖倍率、正负偏移、关闭恢复、重复切换、跳转校准与边界值。设备上的视觉效果及挑战组合仍需实测。
